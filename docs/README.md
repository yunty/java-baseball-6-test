# 기능 목록

### 게임 진행 순서

1. 게임 시작 / 시작 문구 출력
2. 게임진행
    - 난수로 정답 생성하기
    - 사용자 입력받기 (숫자)
    - 입력값 검증
    - 게임 결과 계산
    - 결과 출력하기
4. 3스트라이크가 될떄까지 반복
5. 종료시 안내문구 (종료인지 재시작인지)

# 기능 리스트

- 게임 시작
- 난수 생성하기 / 각 자리의 숫자가 겹치지 않는 3자리 정수
- 시작문구 출력하기
    - "숫자 야구 게임을 시작합니다."
- 입력문구 출력하기
    - "숫자를 입력해주세요 : " / 줄띄움 x
- 사용자 입력받기 (숫자)
- 입력값 검증하기 / 빈값인경우, null인 경우, 문자열인 경우 (숫자로 치환 후 안될 시 예외), 3자리가 아닌경우
- 게임 결과 계산하기
- 결과 출력하기
- 종료 안내문구 출력하기

### 입력받기 - InputView

#### 기능

- 사용자 숫자 받기 getUserNumber ()
- 재시작 여부 값 받기 getExitOrAgain ()

### 출력하기 - OutputView

#### 기능

- 시작문구 출력하기 printStart ()
- 입력문구 출력하기 printInput ()
- 종료 안내문구 출력하기 printExitOrAgain ()
- 문자열 입력받아 출력하기 print ()

### 게임 -Game

#### 상태

- int answer / 난수 생성 클래스의 값 받아오기

#### 기능

- 입력값에 따른 결과 값 메소드 getResult ()
